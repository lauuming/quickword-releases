# Quickword releases

Quickword lets you talk instead of typing. Hold a shortcut, speak, let go, and the cleaned-up text appears wherever your cursor is. It is free, needs no account, and does the work on your own computer.

This repository holds the installers and the auto-update feed. The application source is not public.

- Windows 10/11: download the latest `Quickword_x.y.z_x64-setup.exe` from Releases.
- macOS (Apple silicon): download the latest `Quickword_x.y.z_aarch64.dmg`. Intel Macs are not built yet.
- Android: `Quickword_android_x.y.z-test.apk` is a test build.

The installers are not code signed yet, so Windows and macOS warn on first launch. On Windows choose More info, then Run anyway. On macOS right-click the app and choose Open.
